# 🪐 VADIM - OS v5.0 (Ultra Release)

**VADIM - OS** — это многофункциональный мини-браузер и оверлей-помощник, встраиваемый прямо в страницы Школьного портала (`mosreg.ru`) и Дневник.ру (`dnevnik.ru`).

---

## ✨ Ключевые возможности

* 📑 **Мульти-вкладки:** Создавайте, закрывайте и переключайтесь между несколькими сайтами одновременно.
* 🚨 **Паник-кнопка:** Мгновенное скрытие всего браузера по нажатию клавиши **`~`** (буква **Ё**), **`F2`** или кнопки 🚨.
* 🎭 **Режим маскировки (Stealth):** Одной кнопкой маскирует кнопку вызова под «📘 Электронная тетрадь».
* 📝 **Встроенный блокнот:** Автоматически сохраняет ваши конспекты и шпаргалки, умеет скачивать их в `.txt` и озвучивать голосом.
* 🧮 **Умная адресная строка:** Введите выражение (например, `(250*4)/2`) прямо в URL-строку и нажмите **GO** — скрипт выдаст готовый ответ.
* 🌙 **Ночной режим сайтов:** Принудительное включение тёмной темы на любых открытых сайтах внутри окна.
* 🔍 **Управление масштабом:** Кнопки **🔍+** и **🔍-** для точной настройки масштаба загруженных страниц.
* ⏱️ **Таймер и Секундомер:** Отсчёт времени для контроля сдачи тестов и контрольных.
* 🎲 **Рандомайзер ответов:** Генератор случайных чисел (1–4), режимы «Да/Нет» и кастомный диапазон для тестов.
* 🧘 **Zen-Режим:** Полное скрытие элементов управления для фокуса на содержимом (выход по `ESC`).
* 📦 **Экспорт / Импорт:** Сохранение закладок, заметок и настроек в JSON-файл для переноса на другой ПК.

## 📥 Инструкция по установке

1. Установите расширение **Tampermonkey** в ваш браузер (Chrome, Edge, Firefox, Yandex).
2. Нажмите на иконку Tampermonkey ➔ **«Панель управления»** (Dashboard).
3. Перейдите во вкладку **«Утилиты»** или нажмите иконку **`+`** (Создать новый скрипт).
4. Удалите шаблонный код, вставьте полный код файлу `vadim-os.user.js` и нажмите **`Ctrl + S`** для сохранения.
5. Зайдите на сайт **[dnevnik.ru](https://dnevnik.ru)** или **[mosreg.ru](https://mosreg.ru)** и обновите страницу (`F5`).
